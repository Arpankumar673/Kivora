# Kivora — E-Commerce Web Application

Responsive e-commerce web application for the internship project, built with React, Vite, Tailwind CSS, React Router, Supabase, and Vercel.

## Stack
- **Frontend:** React + Vite
- **Styling:** Tailwind CSS + Lucide React Icons
- **Routing:** React Router DOM (v6+)
- **Backend Platform:** Supabase (Auth, PostgreSQL, RLS, Realtime)
- **Deployment:** Vercel

## Environment Configuration
Copy `.env.example` to `.env` and set your Supabase API credentials:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
